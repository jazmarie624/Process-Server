The five that end a career

  • Never sign a return you're unsure about. A false return is a third-degree felony and a lifetime ban.
  • Never serve on a Sunday. Void service, and you're personally liable for damages.
  • Never serve a case you have any stake in. You must be disinterested.
  • Never imply you're law enforcement. It's a crime and it voids the serve.
  • Never let the bond or ID card lapse. An expired card is something opposing counsel can attack.
